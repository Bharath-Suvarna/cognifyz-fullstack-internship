# Event Management System

## Project Overview

The Event Management System is a full-stack web application for creating, viewing, managing, and registering for events. It includes user authentication, event pages, form handling, dashboard views, API routes, and MongoDB-based data storage.

This project is organized into multiple levels to separate frontend assets, backend routes, database models, and dashboard functionality.

## Features

- User registration and login
- Event listing and event details pages
- Add and edit event functionality
- Event registration support
- Dashboard page for event-related data
- API routes for backend data handling
- Contact and form handling
- Weather page integration placeholder
- Request logging middleware
- Cache cleanup middleware
- MongoDB database connection using Mongoose

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript, EJS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JSON Web Token
- **Environment Variables:** dotenv
- **Version Control:** Git and GitHub

## Installation Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/Bharath-Suvarna/cognifyz-fullstack-internship.git
   ```

2. Go to the project folder:

   ```bash
   cd cognifyz-fullstack-internship
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file in the project root and add your environment variables:

   ```env
   PORT=3000
   MONGO_URI=your_mongodb_connection_string
   JWT_SECRET=your_jwt_secret
   ```

5. Start the application:

   ```bash
   npm start
   ```

6. Open the app in your browser:

   ```text
   http://localhost:3000
   ```
